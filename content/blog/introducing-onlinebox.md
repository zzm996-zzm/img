## What is OnlineBox?

OnlineBox is a growing collection of free browser-based tools built for developers, designers, and everyday users. Every tool runs locally in your browser — nothing is uploaded to a server, nothing is tracked, your files never leave your device.

## Current Tools

### Image Tools
- **[Image Compressor](https://onlinebox.site/image-compressor)** — Compress images to an exact KB target without losing more quality than necessary.
- **[Image Converter](https://onlinebox.site/image-converter)** — Convert images between PNG, JPG, WebP and other formats instantly.
- **[Image Resizer](https://onlinebox.site/image-resizer)** — Resize images to exact dimensions while preserving aspect ratio.
- **[Batch Image Compressor](https://onlinebox.site/batch-image-compressor)** — Compress multiple images at once.

### Developer Tools
- **[CSV to JSON](https://onlinebox.site/csv-to-json)** — Paste CSV data and convert it to clean JSON instantly.
- **[JSON Formatter](https://onlinebox.site/json-formatter)** — Format, validate and minify JSON in one click.
- **[M3U8 Player](https://onlinebox.site/m3u8-player)** — Play any HLS stream directly in your browser with speed control and fullscreen support.

### Creator Tools
- **[QR Code Generator](https://onlinebox.site/qr-code-generator)** — Generate QR codes for any URL or text, download as PNG.
- **[Social Card Maker](https://onlinebox.site/social-card-maker)** — Create clean social media preview cards for Twitter, LinkedIn and more.
- **[Markdown to PDF](https://onlinebox.site/markdown-to-pdf)** — Convert Markdown documents to clean, printable PDFs.
- **[Gradient Generator](https://onlinebox.site/gradient-generator)** — Create beautiful CSS gradients and copy the code instantly.

## Why browser-based?

Most online tools send your files to a server for processing. That means your data — images, documents, spreadsheets — passes through someone else's infrastructure.

OnlineBox takes a different approach: every tool runs entirely in your browser using JavaScript. The processing happens on your device. We never see your files.
