## Quick answer

If you can already open a PDF but it blocks copying, printing or editing, use the [OnlineBox PDF Unlocker](/pdf-unlocker). Upload the PDF in your browser and the tool rebuilds a downloadable copy with permission restrictions removed.

## What this tool can remove

PDF files can include permission flags that limit copying text, printing pages or editing the document in other software. The [PDF Unlocker](/pdf-unlocker) is designed for those permission restrictions.

It does not remove open passwords. If a PDF asks for a password before you can view it, this tool cannot unlock it.

## Step by step

1. Open [PDF Unlocker](/pdf-unlocker).
2. Drop your PDF into the upload area.
3. Wait while the browser rebuilds the file locally.
4. Download the unlocked PDF when processing finishes.

## When it is appropriate

Use this only for documents you own or have permission to modify. Common examples include old exported reports, internal documents, scanned PDFs from your own archive or files where permission flags were added accidentally.

## Privacy note

The file is processed locally with pdf-lib in your browser. OnlineBox does not upload the PDF to a conversion server.

## FAQ

### Can it remove a PDF open password?

No. It removes permission restrictions only, not open passwords.

### Can it unlock printing?

It can rebuild PDFs that are already openable and have print permission restrictions.

### Can it unlock editing?

It can remove edit permission flags from many openable PDFs. Some encrypted or damaged files may not be supported.
